# Goblin Fortress

A playable-goblin mod for Dwarf Fortress Classic 0.47.05.

Play as the goblins: [SITE_CONTROLLABLE] goblin entity with its own playstyle, custom buildings (Dark Altar, Bone Pit, War Pit), and a Shaman profession whose magic (via the repurposed Alchemy skill) unlocks in tiers through bone-focus reagents. Includes the Goblin Cellar full graphic tileset (32x32) and Goblin Therapist — Dwarf Therapist 41.2.5 with a Goblin Fortress grid view (Shaman Rites, Water and Meat, Pit and Trophies, Fortress Craft labor groups).

## Download

Get the full package (mod + Goblin Therapist) from the v1.0.0 release on this repo.

## Installing the mod

1. Copy the contents of "Goblin Fortress Mod" into the Dwarf Fortress Classic 0.47.05 folder, merging folders and replacing the matching raw files.
2. The included data/init/init.txt enables graphics and selects the Goblin Cellar tileset. Init settings are global to the game. Back up your existing init.txt first if it contains settings you want to keep.

## Running Goblin Therapist

Run Goblin Therapist/GoblinTherapist.exe, then connect it to the running Dwarf Fortress process.
