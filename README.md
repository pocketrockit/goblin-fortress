# Goblin Fortress

A playable-goblin mod for Dwarf Fortress Classic 0.47.05.

Play as the goblins: [SITE_CONTROLLABLE] goblin entity with its own playstyle, custom buildings (Dark Altar, Bone Pit, War Pit), and a Shaman profession whose magic (via the repurposed Alchemy skill) unlocks in tiers through bone-focus reagents. Includes a full graphic tileset (32x32) — the default is now the Pastel Fairytale set, with complete creature graphics for all 725 vanilla creatures — and Goblin Therapist — Dwarf Therapist 41.2.5 with a Goblin Fortress grid view (Shaman Rites, Water and Meat, Pit and Trophies, Fortress Craft labor groups).

## Download

Get the full package (mod + Goblin Therapist) from the v1.0.2 release on this repo (Latest). Earlier releases keep the previous default art: v1.0.1 (Earthtone set) and v1.0.0 (original Goblin Cellar set).

## Installing the mod

1. Copy the contents of "Goblin Fortress Mod" into the Dwarf Fortress Classic 0.47.05 folder, merging folders and replacing the matching raw files.
2. The included data/init/init.txt enables graphics and selects the Pastel Fairytale tileset. Init settings are global to the game. Back up your existing init.txt first if it contains settings you want to keep.

## Running Goblin Therapist

Run Goblin Therapist/GoblinTherapist.exe, then connect it to the running Dwarf Fortress process.
